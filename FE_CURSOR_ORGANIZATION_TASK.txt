WHAT CHANGED (backend behavior you must mirror in UI)
================================================================================

BEFORE                          AFTER
------                          -----
clientId on user                organizationCode (string, e.g. "CL001")
(no org entity)                 organizationId (Mongo ObjectId on user + order)
orders = per user               orders = per organization (all members see all)
only admin adds users           admin OR any client in org can add users
client signs up freely          sign-up requires existing organizationCode

WORKERS: unchanged — no organization fields.

================================================================================
FIELD DICTIONARY (do not confuse these)
================================================================================

organizationCode  = business code string "CL001" (was clientId)
organizationId    = MongoDB _id string linking user/order to Organization
Organization      = { _id, name, organizationCode, isActive }

================================================================================
API FUNCTIONS TO ADD/UPDATE (axios/fetch layer)
================================================================================

AUTH (update)
  login({ phoneNumber, password })
  signUp({ fullName, phoneNumber, password, organizationCode })
  verify({ userId, code })

ADMIN (new)
  createOrganization({ name, organizationCode }, token)
  listOrganizations(token)
  getOrganizationById(organizationId, token)

ADMIN (update)
  addClientUser({ fullName, phoneNumber, password?, organizationCode? | organizationId? }, token)
  REMOVE from body: role, username, clientId

CLIENT (new)
  listOrganizationMembers(token)          -> GET  /clients/users
  addOrganizationMember({ fullName, phoneNumber, password? }, token) -> POST /clients/users

CLIENT (behavior only — same URLs)
  getClientOrders(token)     -> returns ALL org orders
  createOrder(...)           -> 400 if user has no organizationId
  updateOrder(...)           -> can edit any order in same org
  updateProfile(...)         -> body: { fullName?, phoneNumber? } only

================================================================================
REQUEST / RESPONSE EXAMPLES
================================================================================

--- POST /auth/login ---
REQUEST:  { "phoneNumber": "0501234567", "password": "password123" }
RESPONSE: { "success": true, "token": "...", "user": { "_id", "fullName", "phoneNumber", "role", "organizationCode", "organizationId", ... } }

--- POST /auth/signUp ---
REQUEST:  { "fullName", "phoneNumber", "password", "organizationCode": "CL001" }
ERROR:    { "success": false, "error": "Organization not found for this code. Contact your administrator." }

--- POST /admin/organizations ---
REQUEST:  { "name": "Acme Ltd", "organizationCode": "CL001" }
RESPONSE: { "success": true, "organization": { "_id", "name", "organizationCode", "isActive" } }

--- GET /admin/organizations ---
RESPONSE: { "success": true, "organizations": [ ... ] }

--- GET /admin/organizations/:organizationId ---
RESPONSE: { "success": true, "organization": { ... }, "users": [ ... ] }

--- POST /admin/users ---
REQUEST:  { "fullName", "phoneNumber", "organizationCode": "CL001" }
       OR { "fullName", "phoneNumber", "organizationId": "<mongoId>" }
RESPONSE: { "success": true, "user": { "userId", "username", "fullName", "role", "organizationCode", "organizationId" } }

--- GET /clients/users ---
RESPONSE: { "success": true, "users": [ { "_id", "fullName", "phoneNumber", "organizationCode", ... } ] }

--- POST /clients/users ---
REQUEST:  { "fullName", "phoneNumber", "password" }
RESPONSE: { "success": true, "message": "User added to your organization successfully", "user": { ... } }
ERROR:    { "success": false, "error": "Your account is not linked to an organization." }

--- POST /clients/orders ---
ERROR:    { "success": false, "error": "Your account is not linked to an organization. Contact your administrator." }

--- PUT /clients/users/:userId ---
REQUEST:  { "fullName", "phoneNumber" }   // NO organizationCode
